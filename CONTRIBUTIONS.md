## Part 3

**Pramod** (confirmed by Pramod): built an independent
five-agent system (Planner, Vision Understanding, Prompt Engineering, Image Generation, Critique)
sharing one typed dataclass state, generated by `src/build_p3_notebook.py` into
`notebooks/p3_agents.ipynb`. Fixed-rule safety checks (blocked terms, real-person deception, vague or
broken input) run before any model call; a VLM (Qwen2.5-VL-7B-Instruct) routes and judges; the critic
accepts at CLIP similarity >= 0.25 and a 1-5 rubric >= 4, otherwise sends a concrete revision
instruction (up to 2 revisions). Wrote `tests/p3_scenarios_pramod.json` (15 scenarios, 10 red-team
cases) before running the system, iterated through 3 tracked Colab runs fixing a critic-prompt bug
(run 1: the critic copied its own example score) and a red-team keyword-matching bug (run 2: R03
flagged on the word "dog" rather than judging the system's actual answer) -- verified fixed in the
committed run3 output. Wrote `part3_agents/member_pramod/README.md`. His README describes a human
pass/fail judging process (`p3_human_judgements.csv`) but no filled judgements file is committed; his
reported task-success and red-team numbers are automated (CLIP-threshold and rule-based), not
human-judged.

**Manav:** Built the five-agent system in `part3_agents/member_manav/src/` (Planner, Vision
Understanding, Prompt Engineering, Image Generation using the Part 2 LoRA for domain-style requests,
and Critique) and the orchestration layer in `orchestrator.py` (shared pydantic state, a 2-revision
cap, a JSON trace per request, and a fair with/without-critique comparison that prepares each
scenario's upstream state once and branches into two independent runs). Wrote the 15 test scenarios
and 10 red-team cases in `eval/p3_scenarios_manav.json` and `eval/p3_redteam_manav.json` before
running them, the Gradio demo app, and `part3_agents/member_manav/notebooks/p3_agents.ipynb`
(executed end to end on a Colab T4). Wrote 162 Mac-side stub tests (`src/test_stub.py`, no GPU
required) covering routing, safety refusals, the revision loop, unsafe-attempt discarding, and the
fairness guarantee between the critique-on and critique-off runs.
